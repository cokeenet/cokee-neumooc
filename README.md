# neumooc-platform · 东软智慧教育 Web 操作平台

把散落的脚本升级成**带界面、可调度、可观测、多账号**的学习自动化平台。

---

## 致谢

本项目建立在 [**LuBanQAQ/NEUMOOC-Auto-Sign**](https://github.com/LuBanQAQ/NEUMOOC-Auto-Sign) 打下的基础上。

那个项目把东软智慧教育 App 的全量接口（56 个）从 APK 静态分析中整理出来，
并给出了可直接运行的 Python 客户端与 Go SDK —— 包括最容易踩的几处协议细节：

- `Id-Code` 请求头：AES-128-CBC，**key 与 iv 是同一个常量**，零填充
- 登录接口对 `User-Agent` 敏感，必须用 uni-app 风格
- `code=401` 要刷新令牌后重试一次
- 交卷用 `PUT /smartexam/test/student/submit?historyId=`，**不是** `testId`

没有那份文档与实现做对照，这个项目的协议层不可能对齐得这么快。
**感谢 LuBanQAQ 的整理与公开。**

本仓库的协议层是按上述公开事实**独立重写**的（Rust），未复制其代码；
在此基础上增加了 Web 界面、多账号隔离、调度与自动化能力。详见 [独立实现说明](#独立实现说明)。

## 技术栈

| 层 | 选型 |
| --- | --- |
| 后端 | Rust（axum + rusqlite），每账号串行 worker |
| 协议层 | Rust（无 Web / 无数据库依赖） |
| 数据库 | SQLite（WAL） |
| 前端 | Astro 7 + React 19 岛屿 + Tailwind v4 |
| 实时日志 | SSE |

## 目录结构

```
neumooc-platform/
├── rust/
│   ├── core/       协议层（无 Web / 无数据库依赖）
│   └── server/     axum 后端：db / store / worker / scheduler / api
└── web/            Astro 前端
    ├── src/pages/
    ├── src/components/
    └── src/middleware.ts   鉴权守卫（必须在中间件，不能放 layout）
```

## 环境

```bash
# 后端（Rust）
cd rust && cargo build --release -p neumooc-server

# 前端
cd web && pnpm install && pnpm build

# 运行需要这些环境变量（无默认值，缺失会明确报错）
export NEUMOOC_BASE_URL=https://example.edu.cn
export NEUMOOC_TENANT_ID=0000000000000000000
export NEUMOOC_DATA=/path/to/data      # 放 neumooc.db 与 secret.key
```
